# Lab 10 - PHP Web Applications

This repository contains three PHP lab applications.

## Applications

### Question A - Session and Logout
- Accepts a visitor's name.
- Stores the name and login time in a PHP session.
- Displays the start time on the welcome page.
- Calculates and displays the session duration after logout.

### Question B - Date, Time and Day
- Displays the current date, time and day using PHP date functions.

### Question C - Age Verification
- Accepts a visitor's name and age.
- Displays the not-authorized message when the age is below 18.
- Displays the welcome message when the age is 18 or above.

## Folder Structure

- `Question_A_Session/`
- `Question_B_Date_Time/`
- `Question_C_Age_Verification/`

## How to Run

1. Install XAMPP and start Apache.
2. Copy the `LAB10_PHP_Friend` folder into `C:\xampp\htdocs`.
3. Open these URLs:

- A: `http://localhost/LAB10_PHP_Friend/Question_A_Session/`
- B: `http://localhost/LAB10_PHP_Friend/Question_B_Date_Time/datetime.php`
- C: `http://localhost/LAB10_PHP_Friend/Question_C_Age_Verification/`

PHP must be run through a local server such as XAMPP. GitHub Pages does not execute PHP.
